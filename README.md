# ps5upload-bin

Unofficial [AUR](https://aur.archlinux.org/packages/ps5upload-bin) package for
[PS5Upload](https://github.com/phantomptr/ps5upload). It repackages upstream's
prebuilt `.deb` release for Arch Linux (x86_64 and aarch64).

## Install

```sh
yay -S ps5upload-bin
```

## Reporting problems

- Bugs in the app itself go to upstream:
  <https://github.com/phantomptr/ps5upload/issues>
- Packaging problems (missing dependencies, install errors, outdated version)
  go to this repo's issues or the AUR package comments.
